# Support

Use the repository's public channels for non-sensitive support:

- bug reports: GitHub Issues using the bug template;
- feature and backend proposals: GitHub Issues using the feature template;
- usage questions and design discussion: GitHub Discussions;
- vulnerabilities: private reporting described in [SECURITY.md](SECURITY.md).

Include `cmdtrail --version`, operating system, backend from `capabilities`,
limits, safe reproduction steps, and a redacted receipt when relevant.

Do not post real secrets, private paths, internal hostnames, or confidential
receipts. A receipt can contain sensitive operational metadata even after
pattern-based redaction.

Community support is best-effort. Security response targets are defined in
[SECURITY.md](SECURITY.md).
