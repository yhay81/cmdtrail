# Adopters and feedback

CmdTrail needs evidence of real, repeat use before v1.0. Synthetic fixtures,
maintainer-only testing, release downloads, and stars do not count as adoption.

No independent adopter has been verified yet.

To share an adoption, open an issue or pull request with as much of the
following as can be public:

- organization, project, or pseudonymous user name;
- operating system and CmdTrail backend;
- command class, such as installer, generator, or build;
- decision the receipt helped make;
- whether use repeated after at least 30 days;
- limitations or false positives encountered;
- permission to list the report here.

Privacy-preserving evidence is welcome. Never include secrets, confidential
paths, internal hosts, or an unreviewed receipt.
